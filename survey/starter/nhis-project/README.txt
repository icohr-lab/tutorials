NHIS practice project for the "R for Survey Data" tutorials
https://icohr-lab.github.io/tutorials/survey/

1. Open this project by double-clicking nhis-project.Rproj.
2. Open prepare.R and run it (Source button) to create data/nhis_analysis.rds.
3. Follow the lessons on the website, typing your code into n3.R, n4.R, and so on.
   nchs_reliability.R holds a helper function used in lesson N7.

Data: a subset of the 2025 National Health Interview Survey Sample Adult public-use file,
National Center for Health Statistics (https://www.cdc.gov/nchs/nhis/). Public domain.
