# Notebook generator

The `.ipynb` files in `notebooks/` are generated by these scripts. **Edit the scripts, then rebuild; do not edit the notebooks by hand**, or the next rebuild will overwrite your changes.

| File | Builds |
|---|---|
| `nbkit.py` | Shared toolkit: notebook header, exercises, recap, solutions, "Next" links, file names, and URLs |
| `foundations.py` | F1–F3 |
| `foundations2.py` | F4–F6 |
| `path_a.py` | A1–A6 |
| `path_b.py` | B1–B5 |

Only the Python standard library is needed.

## Rebuild

From the project root:

```bash
for f in foundations foundations2 path_a path_b; do python3 notebooks/generator/$f.py; done
```

This writes the notebooks to `notebooks/` and two R test scripts per notebook (blank and solved) to `notebooks/generator/tests/` (ignored by git).

## Test

```bash
bash notebooks/generator/runtests.sh F1 F2 F3 F4 F5 F6 A1 A2 A3 A4 A5 A6 B1 B2 B3 B4 B5
```

Needs R with tidyverse and broom, and an internet connection (the data are read from GitHub). Every "solved" run should finish with `exit=0 errors=0`. In "blank" runs, A2, A3, and B2 stop early because later cells depend on an unfinished exercise; that is expected.

To build somewhere else, for example to compare with the committed notebooks, set `NB_OUT` and `NB_TEST`.
